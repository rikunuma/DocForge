# 総合テストケース仕様書 (Test Cases & Test Matrix)

## 1. 概要
DocForge（帳票作成プラットフォーム）の品質を保証するためのテスト仕様書です。
単体テスト、API結合テスト、UI/UX機能テスト、PDFレンダリング表示テスト、異常系・境界値テストを網羅します。

---

## 2. テスト環境・前提条件
* **OS / ブラウザ**: macOS / Windows / iOS / Android, Chrome, Edge, Safari
* **バックエンド**: Python 3.11, FastAPI, ReportLab 4.3, PostgreSQL 16
* **フロントエンド**: Next.js 16 (React 19)

---

## 3. テストマトリクス & テストケース一覧

### 3.3 PDF レンダリング・フォント表示品質テスト

| ID | テスト対象 | テスト条件・操作 | 期待結果 | 判定 |
|---|---|---|---|---|
| **TC-PDF-01** | 日本語フォント表示 | 生成された PDF を Chrome / Edge / Acrobat で閲覧 | 漢字、ひらがな、カタカナ、数字が文字化け・豆腐化せず完全描画されること | PASS |
| **TC-PDF-02** | フォント埋め込み確認 | PDF バイナリヘッダーの解析 (`re.search`) | IPAゴシック (`IPAGothic`) / IPA明朝 (`IPAMincho`) がサブセット埋め込みされていること | PASS |
| **TC-PDF-03** | メタデータ確認 | PDF プロパティ情報（Document Info）の確認 | `Title` に書類タイトル、`Author` に自社会社名が設定され `anonymous` が消去されていること | PASS |
| **TC-PDF-04** | 金額のフォーマット | 単価 `350000`, 数量 `2` を入力 | 明細金額 `¥700,000`、小計・消費税・合計がカンマ区切りで綺麗に整列表示されること | PASS |

### 3.4 異常系・境界値・セキュリティテスト

| ID | テスト対象 | テスト条件・操作 | 期待結果 | 判定 |
|---|---|---|---|---|
| **TC-EX-01** | 長文テキスト入力 | 宛先名や品名に 200 文字以上の長文を入力 | テーブル枠をはみ出さず、改行されて整然と表示されること | PASS |
| **TC-EX-02** | 0円・マイナス数値 | 単価に `0` や `-1000` (値引き) を入力 | 計算ロジックがエラーにならず、値引き・合計金額が正常算出されること | PASS |
| **TC-EX-03** | 特殊文字・記号 | 品名に `<script>`, `&`, `"`, `'`, `〒` などの記号を入力 | HTML Injection が発生せず、安全にエスケープ表示されること | PASS |
| **TC-EX-04** | 存在しないIDへのアクセス | `/api/documents/99999` へアクセス | HTTP 404 Not Found エラーが返却され、アプリがクラッシュしないこと | PASS |

## 4. 自動化テスト実行コマンド

### 4.1 FastAPI バックエンド テスト実行
```bash
docker compose exec api pytest
```

### 4.2 Next.js フロントエンド TypeScript・ビルドチェック
```bash
docker compose exec web npm run build
```
